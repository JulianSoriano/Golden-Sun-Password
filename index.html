How the password is built
  1. Everything is packed into bits: 7 per level, 1 per Djinn, 1 per story event and Psynergy item, 60 per character for stats, 9 per item ID, 5 per consumable stack and 24 for coins.
  2. A 16-bit checksum key is run over every byte (start at 0xFFFF, shift left, add 0xEFDF on carry) and then inverted.
  3. Each byte is XORed with the key’s low byte, and both key bytes are appended.
  4. The bits are cut into 6-bit groups. After every 9 groups a check group (their sum mod 64) is added.
  5. Each group gets its own position added (mod 64) and is swapped for one of the 64 password symbols. The alphabet skips 0, 1, I, O, l and o so nothing reads ambiguously on screen.

Password logic ported from the Golden Sun Password Generator spreadsheet by Dyrati (2023). The original Lua is at github.com/Dyrati/Golden-Sun-Password-Transfer.
